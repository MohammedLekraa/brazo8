01. Objetivos del Proyecto

Objetivo General

Reproducir los movimientos de la mano humana en un brazo robótico antropomórfico en tiempo real.

Objetivos Específicos

  • Dedos: Captura y control individualizado de flexión y extensión.
  • Muñeca: Control preciso del movimiento de rotación (pronación/supinación).
  • Comunicación: Enlace inalámbrico robusto de baja latencia mediante Bluetooth.

02. Planteamiento del Sistema

El sistema se estructura en un flujo continuo de tres etapas: captura, transmisión inalámbrica y reproducción del movimiento.

1. CAPTURA

Guante Sensorizado

Flex Sensors capturan la flexión de los dedos. El módulo IMU MPU6050 mide la inclinación/rotación de la muñeca.

➔
2. TRANSMISIÓN

Bluetooth SPP

Conexión inalámbrica directa entre dos microcontroladores ESP32 a una frecuencia de 10 Hz (cada 100 ms).

➔
3. REPRODUCCIÓN

Brazo Robótico

5 servomotores mueven los dedos mediante hilos de tracción. 1 servomotor rotatorio actúa sobre la muñeca mediante engranajes.

03. Diseño Mecánico del Brazo

Estructura e Impresión 3D

Se integró la estructura del antebrazo del proyecto InMoov combinada con la mano de modelo FlexyHand, seleccionada por ofrecer mayor resistencia mecánica y durabilidad en las articulaciones.

Puntos de Anclaje y Actuación

Se diseñaron piezas 3D de acoplamiento a medida para fusionar ambas estructuras. Los dedos operan mediante hilos guiados conectados a 5 servos independientes, mientras que la muñeca utiliza un engranaje directo movido por el sexto servomotor.

04. Guante Sensorizado: Captura de Movimiento

El guante concentra todos los elementos de adquisición de datos organizados compactamente sobre el dorso de la mano y la muñeca:

Flex Sensors

Ubicados a lo largo de cada dedo para medir el grado de flexión articular.

MPU6050

Situado en la muñeca para determinar la orientación angular de la mano.

Caja Electrónica

Alberga el microcontrolador ESP32-WROOM-32D, la PCB personalizada y la batería de alimentación.

05. Sensor de Flexión: Lectura y Conversión

Los sensores varían su resistencia al doblarse. Mediante un circuito divisor de tensión, convertimos esta variación de resistencia en un voltaje analógico leído por el ADC del ESP32.

Ecuación de Conversión (`map`)

Convertimos los valores analógicos brutos (ADC) a ángulos entre 180° y 0° mediante mapeo lineal:

int angle = map(flexADC, minFlex, maxFlex, 180, 0);

06. Unidad de Medida Inercial: MPU6050

El giroscopio sufre de deriva con el tiempo y el acelerómetro presenta ruido por vibraciones. Implementamos un Filtro Complementario para combinar la precisión de ambos en tiempo real.

Fórmula del Filtro Complementario:

Roll = 0.98 * (Roll + GyroX * dt) + 0.02 * AccelRoll

Comparativa: Deriva vs. Filtro Complementario

07. Esquema de Alimentación

Guante

Alimentado de forma autónoma mediante una batería recargable de 9V conectada al ESP32.

Microcontrolador Brazo

Alimentado por 2 pilas 18650 en serie (6.4V - 7.4V) aisladas eléctricamente.

Servomotores

Fuente de alimentación externa regulada a 6.4V para soportar picos de corriente elevados.

08. Comunicación Bluetooth SPP

  • Protocolo: Bluetooth SPP (Serial Port Profile) con arquitectura Cliente (Guante) ➔ Servidor (Brazo).
  • Enlace: Conexión directa automática reconociendo la dirección MAC física del dispositivo receptor.
  • Frecuencia: Trama transmitida cada 100 ms (10 Hz) para evitar saturación del canal.
  • Formato de Trama: <flex1> <flex2> <flex3> <flex4> <flex5> <roll_servo>

09. Dificultades Encontradas y Soluciones

⚡

Interferencias en Servos

Problema: Los picos de corriente reseteaban el ESP32.

Solución: Separación estricta de las líneas de alimentación entre lógica y actuadores.

🌀

Deriva y Saltos de Ángulo

Problema: Descontinuidad en la lectura MPU6050 al rotar ±180°.

Solución: Aplicación de Filtro Complementario y algoritmo de unwrapping.

🖐️

Rigidez en Bisagras

Problema: El filamento rígido impedía doblar los dedos con fluidez.

Solución: Reimpresión articular en filamento flexible TPU con menor relleno.

10. Código Fuente Principal (ESP32 Receptora)

receptor_brazo.ino 
#include <BluetoothSerial.h>
#include <ESP32Servo.h>

BluetoothSerial SerialBT;
Servo servos[5];
Servo wristServo;

const int servoPins[5] = {13, 12, 14, 27, 26};
const int wristPin = 25;

void setup() {
  Serial.begin(115200);
  SerialBT.begin("ESP32_Brazo_Receptor");
  
  for(int i = 0; i < 5; i++) {
    servos[i].attach(servoPins[i]);
  }
  wristServo.attach(wristPin);
}

void loop() {
  if (SerialBT.available()) {
    String data = SerialBT.readStringUntil('\n');
    int f1, f2, f3, f4, f5, wrist;
    if (sscanf(data.c_str(), "%d %d %d %d %d %d", &f1, &f2, &f3, &f4, &f5, &wrist) == 6) {
      servos[0].write(f1);
      servos[1].write(f2);
      servos[2].write(f3);
      servos[3].write(f4);
      servos[4].write(f5);
      wristServo.write(wrist);
    }
  }
}
