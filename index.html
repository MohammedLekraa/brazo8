01. Objetivos del Proyecto

OBJETIVO GENERAL

Reproducir los movimientos de la mano humana en un brazo robótico antropomórfico en tiempo real.

OBJETIVOS ESPECÍFICOS
  • 1. Dedos: Flexión y extensión individualizada de cada articulación.
  • 2. Muñeca: Control del movimiento de rotación (pronación/supinación).

03. Diseño Mecánico del Brazo

01. BASE INICIAL

Antebrazo InMoov

Modelo elegido para la estructura del antebrazo. Trabajos anteriores advirtieron que la mano InMoov fallaba con el uso continuo.

02. SELECCIÓN MANO

Mano FlexyHand

Búsqueda de una alternativa menos compleja y más sólida. FlexyHand ofrece mayor resistencia mecánica y durabilidad articular.

05. Sensor de Flexión: Lectura y Conversión a Ángulo

Divisor de Tensión y Mapeo

La variación de resistencia de la tira conductiva se convierte en tensión leída por el ADC. Aplicamos la conversión lineal a ángulo de servomotor:

map(flex, minFlex, maxFlex, 180, 0)

* flex: lectura actual ADC del sensor.
* minFlex / maxFlex: valores de calibración mínima y máxima flexión.

06. Unidad de Medida Inercial: MPU6050

El MPU6050 integra un giroscopio y un acelerómetro de 3 ejes.

1. Obtención de Ángulo vía Giroscopio

El giroscopio mide la velocidad angular ($\omega$). Para obtener los grados de inclinación ($\theta$), integramos en el tiempo:

Angle_gyro = Angle_gyro + Gyro_rate * dt

Problema de Deriva: Al integrar continuamente pequeñas imprecisiones, el ángulo acumulado "deriva" (se desvía del valor real progresivamente) aunque la muñeca esté quieta.

2. Solución: Filtro Complementario

Combinamos la respuesta rápida del giroscopio a corto plazo con la estabilidad del acelerómetro a largo plazo:

roll = 0.98 * roll_gyro + 0.02 * roll_acc

Logramos una medida filtrada limpia sin latencia apreciable.

07. Diseño e Integración de PCBs

Para garantizar una comunicación estable y evitar conexiones sueltas, se diseñaron dos placas de circuito impreso (PCB) utilizando la herramienta KiCad.

PCB 1: Guante Emisor

Integra las conexiones para los 5 Flex Sensors con sus divisores de tensión, el conector para el MPU6050 por I2C, el regulador de energía y el socket para el microcontrolador ESP32.

PCB 2: Brazo Receptor

Acondiciona las salidas PWM del ESP32 para los 6 servomotores con pistas sobredimensionadas para soportar picos de corriente elevados.

09. Comunicación Bluetooth

  • Protocolo: Bluetooth SPP (Serial Port Profile) con arquitectura Cliente (Guante) ➔ Servidor (Brazo).
  • Enlace: Conexión directa mediante dirección MAC.
  • Frecuencia de Envío: 10 Hz (1 trama cada 100 ms) para evitar saturación del canal y pérdida de paquetes.
  • Formato de Trama: Trama estructurada en texto plano con delimitadores.
<flex1> <flex2> <flex3> <flex4> <flex5> <roll_servo>

10. Dificultades Encontradas y Soluciones

⚡

Alimentación de Servos

Problema: Las interferencias y picos de corriente reseteaban el microcontrolador.

Solución: Separar la alimentación de los servomotores de la del microcontrolador.

⚛️

Deriva y Saltos MPU6050

Problema: Error acumulado y discontinuidad en ±180°.

Solución: Filtro complementario + técnica unwrapping (sumar o restar 360°).

⚙️

Rigidez de Bisagras

Problema: Los dedos en PLA penas podían doblarse.

Solución: Reimpresión en TPU con menor relleno consiguiendo flexibilidad.

11. Código Fuente

receptor_brazo.ino 
#include <BluetoothSerial.h>
#include <ESP32Servo.h>

BluetoothSerial SerialBT;
Servo servos[5];
Servo wristServo;

const int servoPins[5] = {13, 12, 14, 27, 26};
const int wristPin = 25;

void setup() {
  Serial.begin(115200);
  SerialBT.begin("ESP32_Brazo_Receptor");
  
  for(int i = 0; i < 5; i++) {
    servos[i].attach(servoPins[i]);
  }
  wristServo.attach(wristPin);
}

void loop() {
  if (SerialBT.available()) {
    String data = SerialBT.readStringUntil('\n');
    int f1, f2, f3, f4, f5, wrist;
    if (sscanf(data.c_str(), "%d %d %d %d %d %d", &f1, &f2, &f3, &f4, &f5, &wrist) == 6) {
      servos[0].write(f1);
      servos[1].write(f2);
      servos[2].write(f3);
      servos[3].write(f4);
      servos[4].write(f5);
      wristServo.write(wrist);
    }
  }
}
