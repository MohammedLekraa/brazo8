01. Project Objectives

GENERAL OBJECTIVE

Replicate human hand and wrist dynamics on an anthropomorphic robotic arm in real time with minimum latency.

SPECIFIC OBJECTIVES
  • Fingers: Individual flexion and extension control for each digit.
  • Wrist: Precise rotation control (pronation / supination).
  • Wireless: Low-latency communication link using Bluetooth SPP.

05. Flex Sensor: Acquisition & Angle Mapping

Voltage Divider & Mapping

Resistance changes from bending are converted into an analog voltage read by the ESP32 ADC. Linear mapping maps raw ADC data directly to servo positioning:

map(flexVal, minFlex, maxFlex, 180, 0)
* flexVal: Current ADC reading.
* minFlex / maxFlex: Calibrated bend extremes.

ADC vs. Angle Response

06. Inertial Measurement Unit: MPU6050

1. Gyroscope Angle Integration

The gyroscope measures angular velocity ($\omega$). Integrating over time provides the tilt angle ($\theta$):

Angle_gyro += Gyro_rate * dt

Drift Problem: Accumulating small sensor errors causes the calculated angle to drift continuously over time even when stationary.

2. Solution: Complementary Filter

Combines fast gyroscope response with long-term accelerometer stability to eliminate drift:

roll = 0.98 * roll_gyro + 0.02 * roll_acc

Delivers a stable and noise-free angle reading without significant lag.

07. Custom PCB Design & Electronics

To eliminate loose wiring and guarantee reliable signal integrity, two custom PCBs were designed using KiCad.

Transmitter PCB (Glove)

Houses voltage dividers for 5 Flex Sensors, I2C routing for MPU6050, power regulation, and socket mount for the ESP32 transmitter.

Receiver PCB (Arm)

Routes PWM signals to 6 high-torque servos with wider copper traces designed to handle peak currents.

09. Bluetooth Communication

  • Protocol: Bluetooth SPP (Serial Port Profile) in Client (Glove) ➔ Server (Arm) architecture.
  • Transmission Rate: 10 Hz (1 packet / 100 ms) preventing buffer saturation and packet drop.
  • Data Format: Formatted string payload with custom delimiters.
<flex1> <flex2> <flex3> <flex4> <flex5> <wrist_angle>

10. Challenges & Technical Solutions

POWER

Servo Noise & Brownouts

Issue: High current spikes caused unexpected microcontroller resets.

Solution: Completely isolated power rails for servos and MCU.

IMU

Gyroscope Drift & Discontinuity

Issue: Accumulated position error and ±180° flip jumps.

Solution: Implemented complementary filtering and angle unwrapping.

CAD

Joint Rigidity

Issue: Rigid PLA printed fingers resisted bending motion.

Solution: Reprinted joint sections in flexible TPU filament.

11. Source Code

receiver_arm.ino 
#include <BluetoothSerial.h>
#include <ESP32Servo.h>

BluetoothSerial SerialBT;
Servo servos[5];
Servo wristServo;

const int servoPins[5] = {13, 12, 14, 27, 26};
const int wristPin = 25;

void setup() {
  Serial.begin(115200);
  SerialBT.begin("ESP32_Arm_Receiver");
  
  for(int i = 0; i < 5; i++) {
    servos[i].attach(servoPins[i]);
  }
  wristServo.attach(wristPin);
}

void loop() {
  if (SerialBT.available()) {
    String data = SerialBT.readStringUntil('\n');
    int f1, f2, f3, f4, f5, wrist;
    if (sscanf(data.c_str(), "%d %d %d %d %d %d", &f1, &f2, &f3, &f4, &f5, &wrist) == 6) {
      servos[0].write(f1);
      servos[1].write(f2);
      servos[2].write(f3);
      servos[3].write(f4);
      servos[4].write(f5);
      wristServo.write(wrist);
    }
  }
}
